# مواد عرض ARVYQEN

- `google-play-listing-ar.md`: الاسم واللمحة القصيرة والوصف الكامل المقترح.
- `feature-graphic.svg`: تصميم رئيسي بنسبة 1024×500 (مصدر SVG).
- `01-learning-path.svg` إلى `04-quiz-progress.svg`: أربع لوحات عرض عمودية بنسبة 9:16.
- `arvyqen-icon.svg`: مصدر أيقونة الهوية.

ملفات SVG هي ملفات مصدر قابلة للتحويل إلى PNG أو JPEG قبل رفعها إلى Google Play. الأيقونة المطلوبة للمتجر يجب تجهيزها بصيغة PNG بمقاس 512×512، والصورة الترويجية بمقاس 1024×500. لقطات المتجر يجب أن تطابق التطبيق الحقيقي؛ اللوحات العمودية الحالية تصاميم توضيحية وليست لقطات شاشة ملتقطة من إصدار أندرويد نهائي.
