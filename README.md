# أكاديمية نور الدين

منصة تعليمية متخصصة في التحليل الفني والأسواق المالية.

## ماذا ستتعلم؟
- أساسيات التداول.
- قراءة الشموع اليابانية.
- التحليل الكلاسيكي.
- الدعوم والمقاومات.
- النماذج السعرية.
- المؤشرات الفنية.
- إدارة رأس المال والمخاطر.
- نظريات التحليل المتقدمة.

## المختبر التفاعلي
مساحة عملية لرسم الشموع والمؤشرات وتحليل حركة الأسعار وتطبيق النظريات.

## إعداد
نور الدين ابو رمان
