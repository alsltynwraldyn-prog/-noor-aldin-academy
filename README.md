# ORVEXAL — Trading Education Academy

أكاديمية عربية لتعلّم الأسواق المالية والتحليل الفني، بواجهة عربية RTL وهوية بصرية كحلية وذهبية.

## محتويات المشروع
- واجهة رئيسية وصفحات تعليمية ومكتبة ومختبر رسوم بيانية تجريبي واختبارات.
- صفحات التسجيل والدخول واستعادة كلمة المرور عبر Supabase Auth.
- صفحات الحساب والباقات ونتيجة الدفع.
- قاعدة بيانات Supabase بجداول الملفات الشخصية والباقات والطلبات والاشتراكات، مع تفعيل RLS.
- نشر الواجهة الثابتة عبر GitHub Pages.

## الإعداد الحالي
- مشروع Supabase مربوط بملف الواجهة عبر عنوان المشروع وPublishable Key عام فقط.
- أسعار الباقات المسجلة: 15 ديناراً شهرياً و50 ديناراً سنوياً.
- باقتا VIP غير نشطتين حالياً؛ لذلك لا يمكن بدء الدفع أو منح عضوية مدفوعة.
- دالتا الدفع create-checkout وpaytabs-callback منشورتان. توجد أيضاً دالة قديمة باسم clever-handler وليست مسار الدفع المعتمد.
- دالة إنشاء الدفع تتطلب جلسة مستخدم، وتقرأ السعر من قاعدة البيانات. ودالة الإشعار تتحقق من العملية عبر PayTabs قبل تفعيل الاشتراك.

## ما يلزم قبل الإطلاق الفعلي
1. إضافة بيانات التاجر الحقيقية من PayTabs إلى أسرار Supabase: PAYTABS_SERVER_KEY وPAYTABS_PROFILE_ID وSITE_URL.
2. إعداد SMTP وتأكيد البريد وروابط إعادة التوجيه في Supabase Auth.
3. اختبار التسجيل وتأكيد البريد والدخول واستعادة كلمة المرور.
4. اختبار الدفع الناجح والمرفوض والمكرر في Sandbox والتحقق من انتهاء الاشتراك.
5. مراجعة الشروط والخصوصية والاسترداد والإلغاء والضرائب قبل تفعيل الباقات.
6. بعد نجاح الاختبارات واعتماد حساب التاجر، تفعيل الباقات والانتقال إلى بيانات Live.

لا تضع مفاتيح PayTabs أو Service Role في ملفات الواجهة أو GitHub. لا تستخدم مفاتيح وهمية ولا تعتبر العودة إلى صفحة المتصفح إثباتاً للدفع.

## حدود المنصة
- بيانات مختبر الشارت اصطناعية وليست أسعاراً حية أو تاريخية موثقة.
- لا يوجد اتصال بوسيط تداول أو تنفيذ أوامر.
- مزامنة تقدم الدروس عبر الأجهزة ولوحة إدارة بصلاحيات إدارية تحتاج استكمالاً واختباراً قبل ادعاء اكتمالها.
- الاشتراك الحالي مدة ثابتة شهر أو سنة؛ التجديد التلقائي غير مفعّل.
- المنصة تعليمية فقط، ولا تقدم توصيات استثمارية أو ضمانات ربح.
