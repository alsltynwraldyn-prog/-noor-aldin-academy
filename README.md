# ARVYQEN — Trading Education Academy

أكاديمية عربية لتعلّم الأسواق المالية والتحليل الفني، بواجهة عربية RTL وهوية بصرية كحلية وذهبية.

## مكونات المشروع
- واجهة رئيسية ومسار تعليمي ومكتبة ومختبر رسوم بيانية تجريبي واختبارات.
- صفحات حساب المتعلم والتسجيل والدخول واستعادة كلمة المرور باستخدام Supabase Auth.
- صفحة باقات مجانية وVIP شهري وVIP سنوي.
- مخطط قاعدة بيانات Supabase مع Row Level Security داخل `supabase/schema.sql`.
- تعليمات إعداد وربط الخدمات في `supabase/SETUP.md`.
- مواد الهوية ومتجر Google Play داخل `store-assets/`.

## تشغيل الواجهة
افتح `index.html` عبر استضافة HTTPS أو خادم محلي ثابت. صفحات الحسابات تحتاج `supabase-config.js` منسوخاً من `supabase/config.example.js` ومعبأً بعنوان مشروع Supabase ومفتاح anon العام.

## الحسابات والاشتراكات
الواجهة وقاعدة البيانات مهيأتان، لكنهما لن تعملا فعلياً قبل إنشاء مشروع Supabase وتشغيل SQL وإعداد تأكيد البريد وSMTP. خطط VIP غير نشطة عمداً وأسعارها صفر إلى حين اعتماد المالك للأسعار.

## الدفع
لا توجد عملية دفع حقيقية مفعلة حالياً. يجب ربط مزود دفع يقبل نشاط التاجر في الأردن، وإضافة Edge Functions آمنة، ومفاتيح التاجر كأسرار خادمية فقط، والتحقق من إشعارات الدفع من الخادم قبل تفعيل العضوية. لا تضع أي مفاتيح سرية في ملفات الواجهة أو المستودع. راجع `supabase/SETUP.md`.

## حدود مهمة
- بيانات مختبر الشارت اصطناعية وليست أسعاراً حية أو تاريخية موثقة.
- لا يوجد اتصال بوسيط تداول أو تنفيذ أوامر.
- مزامنة تقدم الدروس عبر الأجهزة تحتاج استكمال ربط التقدم بقاعدة البيانات.
- لا توجد حالياً عضوية مدفوعة أو تجديد تلقائي فعّال.
- السياسات القانونية والضرائب والاسترداد والإلغاء تحتاج اعتماداً قبل الإطلاق.

## النشر
يستخدم المشروع GitHub Actions لنشر الواجهة على GitHub Pages. نشر الواجهة وحده لا ينشئ مشروع Supabase ولا ينشر Edge Functions أو يفعّل بوابة الدفع.

المنصة تعليمية فقط، ولا تقدم توصيات استثمارية أو ضمانات ربح.
