# أكاديمية نور الدين

منصة عربية تعليمية للتحليل الفني والأسواق المالية، بواجهة RTL وتصميم كحلي وذهبي.

## أقسام المنصة
- الصفحة الرئيسية والمسار التعليمي.
- مكتبة دروس للمفاهيم الأساسية.
- النظريات والمنهجيات الفنية.
- دليل المؤشرات الفنية.
- النماذج السعرية والشموع اليابانية.
- اختبار تفاعلي من 10 أسئلة مع حفظ أفضل نتيجة محلياً.
- مختبر شموع ومؤشرات وأدوات رسم، مع حفظ الرسومات محلياً.
- حفظ تقدم الدروس على الجهاز نفسه.
- صفحات سياسة الخصوصية وشروط الاستخدام.

## تشغيل محلي
افتح `index.html` في متصفح حديث. لا يحتاج الموقع إلى خادم لتصفح المحتوى الثابت.

## المختبر
بيانات الشموع مولدة محلياً للتدريب وليست أسعاراً حقيقية. لا توجد حالياً وصلة إلى وسيط أو تنفيذ أوامر تداول أو تغذية أسعار مباشرة.

## حدود النسخة الحالية
- تسجيل الدخول غير مفعّل لعدم وجود خادم مصادقة وقاعدة بيانات.
- نموذج التواصل يحتاج عنوان بريد مستلم يحدده مالك الأكاديمية.
- تقدم الدروس والاختبار والرسومات تحفظ محلياً في المتصفح المستخدم، ولا تتزامن بين الأجهزة.
- لا يوجد حالياً نظام إعلانات أو اشتراكات أو دفع إلكتروني.
- صفحات الخصوصية والشروط توضحان حالة النسخة الحالية، وتحتاجان مراجعة قانونية قبل إطلاق خدمات تجارية.

## النشر
يوجد سير عمل GitHub Actions في `.github/workflows/deploy.yml` لنشر ملفات الموقع على GitHub Pages عند كل تحديث للفرع `main`. من إعدادات المستودع، اختر Settings → Pages → Build and deployment → Source → GitHub Actions.

الموقع تعليمي وليس نصيحة استثمارية أو توصية تداول.
