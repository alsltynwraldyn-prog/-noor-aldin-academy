# ARVYQEN — Trading Education Academy

أكاديمية عربية لتعلّم الأسواق المالية والتحليل الفني، بواجهة عربية RTL وهوية بصرية كحلية وذهبية.

## محتويات المنصة
- صفحة رئيسية تعريفية ومسار تعليمي متدرج.
- مكتبة دروس تفاعلية وحفظ تقدم الدروس محلياً.
- شروحات النظريات الفنية والمؤشرات والنماذج السعرية.
- مختبر رسوم بيانية تفاعلي ببيانات شموع اصطناعية وأدوات رسم ومؤشرات.
- اختبار معرفي مع تصحيح فوري وحفظ أفضل نتيجة محلياً.
- صفحات تعريفية وسياسة خصوصية وشروط استخدام وتنبيه مخاطر.
- ملفات الهوية وأيقونة التطبيق ومواد العرض ونص متجر Google Play داخل `store-assets/`.

## تشغيل محلي
افتح `index.html` في متصفح حديث أو شغّل خادماً محلياً ثابتاً من جذر المشروع.

## بيانات المختبر
الشموع المرسومة مولدة محلياً لأغراض التدريب، وليست أسعاراً حقيقية أو تاريخية موثقة. لا يوجد اتصال بوسيط أو تنفيذ أوامر أو تغذية أسعار مباشرة.

## العناصر المؤجلة بطلب مالك المشروع
- تسجيل الحسابات والمصادقة.
- نظام الدفع والاشتراكات.
- تحديد الأسعار والباقات.

## حدود النسخة الحالية
- تقدم الدروس ونتائج الاختبار والرسومات تحفظ محلياً في المتصفح ولا تتزامن بين الأجهزة.
- نموذج التواصل لا يرسل تلقائياً قبل ربط وسيلة تواصل معتمدة.
- لا توجد حالياً إعلانات أو عضويات مدفوعة فعالة.
- لا تُدخل كلمات مرور أو بيانات بطاقات في صفحات النسخة الحالية.
- يجب مراجعة السياسات قانونياً والتحقق من متطلبات Google Play وسياسة البيانات قبل النشر التجاري.

## النشر
يستخدم المشروع GitHub Actions عبر `.github/workflows/pages.yml` لنشر محتوى المستودع على GitHub Pages عند التحديث إلى الفرع `main`.

المنصة تعليمية فقط، ولا تقدم توصيات استثمارية أو ضمانات ربح.
