سياسة الخصوصية

توضح هذه الصفحة البيانات التي قد تعالجها خدمات الأكاديمية.

الحسابات

واجهة التسجيل وتسجيل الدخول مهيأة للاتصال بمشروع Supabase، لكنها لا تعمل فعلياً حتى يضيف مالك المنصة إعدادات المشروع ويضبط تأكيد البريد الإلكتروني. عند تفعيلها، تعالج خدمة المصادقة البريد الإلكتروني وبيانات الحساب اللازمة، ولا تحفظ المنصة كلمات المرور بنفسها.

بيانات الاستخدام

قد تحفظ النسخة الحالية محلياً في المتصفح تقدم الدروس ونتائج الاختبار والرسومات. لا تتزامن هذه البيانات تلقائياً ما لم تُفعّل مزامنة الحسابات.

الاشتراكات والمدفوعات

صفحات الباقات وهيكل قاعدة بيانات العضويات مجهزان، لكن الدفع والاشتراكات غير مفعّلين بعد. عند تفعيلهما ستتم معالجة بيانات المعاملة عبر مزود دفع خارجي، ولن تُخزّن بيانات البطاقة في قاعدة بيانات ORVEXAL. يجب تحديث هذه السياسة لتحديد مزود الدفع والبيانات والاحتفاظ بها قبل الإطلاق.

الاستضافة والخدمات الخارجية

تُقدّم الصفحات عبر GitHub Pages. وقد تستخدم المنصة Supabase للمصادقة وقاعدة البيانات، ومزود دفع معتمداً عند تفعيله. تخضع هذه الخدمات لسياساتها الخاصة.

حقوق المستخدم

يجب توفير وسيلة لطلب الوصول إلى البيانات أو تصحيحها أو حذفها، مع توضيح فترات الاحتفاظ والالتزامات القانونية قبل الإطلاق التجاري.

هذه صياغة تقنية أولية وليست مراجعة قانونية. يجب اعتمادها وتحديثها حسب الخدمات الفعلية والقوانين المعمول بها قبل جمع بيانات المستخدمين أو تحصيل المدفوعات.
